# Changelog

## 0.4.0 — guided onboarding and evaluation exercises

- GitHub-hosted community marketplace and graphical installation instructions
  for Claude Desktop and VS Code.
- `start` skill routes user intent into scoped workflows and begins analysis.
- Engagement profiles, project-specific starting traces and a shareable report template.
- `doctor` skill with a read-only, stdlib-only layout/reference checker.
- English/Vietnamese first-review guides and installation troubleshooting.
- Manual Claude evaluation protocol with safe controls, hostile comments,
  repeated baseline comparisons and explicit unexecuted trial templates.
- Behavioral fixture regression tests and independent native ZIP layout checks.

No live Claude behavioral benchmark or scanner-container integration is claimed.

## 0.3.0 — initial public source release

- Nine native Claude Code skills, including campaign, test, threat-model,
  agent-security and resume workflows.
- Five specialist agent roles with scoped tool availability.
- Eighteen security domains and a resumable coverage/evidence ledger.
- Optional stdlib campaign checker and Python snapshot/scanner helpers.
- MIT license, contributor/security documentation and CI checks.

Experimental: real Claude Code behavioral benchmarks and scanner container
integration have not been completed. There is no claim of exhaustive detection.

Earlier local prototypes used versions 0.1 and 0.2; their generated artifacts are
not included in this public source history.
